# The Village Fresh Doodh

Hisar, Haryana dairy site. Morning delivery of buffalo milk and hand-churned bilona ghee.

- Ghar ka Doodh (Buffalo) — ₹80 per litre
- Bilona Ghee — ₹1400 per kg
- Address: Kaimri Road, near New Grain Market, Hisar, Haryana 125001

Orders stay in the browser on this device. Pay cash or UPI at the door, 5–7 subah.

```bash
npm install
npm run dev
```
